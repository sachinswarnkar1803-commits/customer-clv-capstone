# Processed Analytical Data Directory

This folder holds cleaned, standardized, and feature-engineered datasets generated by the analytical pipeline:
- `clean_transactions.parquet` / `clean_transactions.csv`: Standardized transaction-level analytical dataset with positive completed purchases, return flags, cancellation flags, and revenue.
- `customer_features.parquet` / `customer_features.csv`: Customer-level RFM, tenure, cadence, and behavioral summary features.
- `customer_clv_segments.parquet` / `customer_clv_segments.csv`: Customer-level probabilistic CLV outputs, uncertainty intervals, survival inactivity probabilities, and Next-Best-Action recommendations.
- `cohort_retention_matrix.csv`: Aggregated cohort retention and revenue metrics.
