# Validation Evidence and Contracts

This directory is intentionally versioned so the validation stage is visible in the capstone repository.

## Contents
- `validation_rules.yaml` — configured schema, quality, and temporal validation rules.
- `schema_contract.json` — machine-readable required input schema.
- `audit_trail.json` — generated by `src/validation/validator.py` after the validation pipeline runs. It is not fabricated or pre-populated when the source workbook has not been processed in the current environment.

## Generate the audit evidence
From the project root:

```bash
python -m src.validation.validator
```

The validator writes `audit_trail.json`, a detailed data-quality report under `reports/data_quality_report.md`, and the clean analytical CSV under `data/processed/`.

## Checks covered
- Required columns and expected workbook sheets
- Missing customer identifiers
- Cancellations and returns
- Non-positive quantities/prices
- Extreme quantity/price outliers
- Invalid dates
- Exact duplicate transaction line items
- Temporal split boundaries and leakage prevention
